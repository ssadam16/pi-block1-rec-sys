# Рекомендации фильмов

Программа предлагает популярные фильмы, рекомендации по жанрам и рекомендации на основе оценок похожих пользователей.

В папке `data` лежит небольшой демонстрационный набор. Чтобы загрузить набор данынх MovieLens Latest Small, надо выполнить `python download_dataset.py`. Скрипт сохранит фильмы и оценки туда же. 

В PyCharm выберите Python 3. Запуск:

```text
python main.py --user-id 1 --method content
python main.py --user-id 1 --method collaborative --limit 5
python main.py --method popular
python main.py --evaluate
```

Для новых пользователей и случаев, когда метод не находит подходящих фильмов, используется популярность. Офлайн-оценка скрывает по одной положительной оценке пользователя и считает Precision, Recall, Hit Rate, покрытие каталога и среднее время ответа.
